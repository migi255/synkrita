# Connect from Claude web

Obtain the approved HTTPS MCP URL, Synkrita sign-in, synthetic test IDs, and access to the approved Claude custom web connector. Anthropic's cloud must reach the HTTPS endpoint on port 443. Workspace administrators add the connector for Team or Enterprise members. Eligible individual accounts can add one under **Customize → Connectors**. [Claude custom connector setup and network requirements](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

1. The administrator adds **Custom → Web** under **Organization settings → Connectors**, enters the exact Synkrita URL, selects **Sign in now**, and chooses **Use your own OAuth client** for the pilot. Register `https://claude.ai/api/mcp/auth_callback` with the provider. Supply the approved client ID and, if the provider issued one, the secret through the connector UI. Match the token endpoint authentication method and keep the exact issued client ID allowlisted at Synkrita. [Claude OAuth](https://claude.com/docs/connectors/building/authentication)
2. Under **Customize → Connectors**, select **Connect**. Sign in through Synkrita's identity provider. In a new chat, enable Synkrita in the connector menu.
3. Ask Claude to call `read_public_observation` with the supplied synthetic receipt ID and show its citation. With your own synthetic investigation ID, call `read_investigation` and confirm its marker. Confirm a test partner's ID and a missing ID produce the same unavailable result. Check the approved-use decision with `read_qualified_decision`. The operator verifies OAuth, only three read tools, refresh across expiry and suspension separately for this client.

If the connector cannot reach Synkrita, ask the operator to check the current Anthropic ingress ranges, port 443 and TLS chain. For a callback error check the exact registered URL and client authentication mode. For repeated sign-in check the provider's refresh result, audience, client claim, scope and account status. Disconnect via the connector settings after staging. Hosted OAuth on the selected tenant remains a staging test.
